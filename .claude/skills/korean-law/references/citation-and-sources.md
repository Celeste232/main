# 인용 형식 · 공식 확인처 · 핫라인 총정리

이 스킬의 **신뢰성**은 정확한 인용과 최신 확인에서 나온다. 추측한 조문·사건번호·전화번호를 절대 만들어내지 않는다.

## 1) 법령 인용 형식
- 기본: **「법령명」 제○조 제○항 제○호** (예: 「민법」 제750조, 「성폭력범죄의 처벌 등에 관한 특례법」 제14조의2).
- 약칭이 흔한 법은 정식명칭을 한 번 밝히고 약칭 사용(예: 「성폭력범죄의 처벌 등에 관한 특례법」(성폭력처벌법)).
- 시행령·시행규칙은 「○○법 시행령」 제○조.
- 개정으로 조문·내용이 바뀔 수 있으므로 **시행일·개정 여부**를 의식하고, 불확실하면 확인 권고.

## 2) 판례 인용 형식
- **법원 + 선고일 + 사건번호 + 판결/결정** (예: 대법원 2019. 1. 1. 선고 2018다12345 판결, 헌법재판소 2019. 1. 1. 2018헌마123 결정).
- 사건번호 부호: 민사 '다/가/나', 형사 '도/고', 가사 '므/드', 행정 '두/누' 등.
- **사건번호는 추측 금지 — 먼저 검색.** 인용 전 반드시 아래 "판례·유사사례 검색"으로 실제 판례를 특정하고 출처와 함께 적는다. 검색해도 특정 안 되면 번호를 쓰지 말고 "확인 필요"로 표기하고 `glaw.scourt.go.kr`을 안내.

## 2-1) 판례·유사사례 검색 워크플로우 (필수 — 묻지 않고 수행)

판례·유사사례·최신 개정 확인이 필요하면 **사용자에게 묻지 말고 즉시** 수행한다. "검색해드릴까요?"라고 되묻지 않는다.

1. **검색**: `WebSearch`로 쟁점 핵심어 + "판례/대법원/판결/헌재" 조합. 예) "전세사기 임차인 대항력 판례", "직장 내 성희롱 사업주 책임 대법원".
2. **출처 우선순위(1차 자료 우선)**:
   - 대법원 종합법률정보 **glaw.scourt.go.kr** (판례 원문)
   - **casenote.kr** (무료 판례 검색)
   - 국가법령정보센터 **law.go.kr** / 헌법재판소 **ccourt.go.kr**
   - 찾기쉬운 생활법령 **easylaw.go.kr** (해설)
   - 필요 시 `WebFetch`로 원문·요지 확인.
3. **검증**: 블로그·언론으로 알게 된 사건번호도 1차 DB로 교차확인. 사실관계가 질문과 유사한지 확인.
4. **차단 시 대체 출처로 확정(필수)**: law.go.kr·casenote 등은 자동 접근이 **403으로 막히는 경우가 많다.** 막혔다고 멈추지 말고, **접근 가능한 다른 출처로 같은 사건을 확정**한다:
   - 대법원 보도자료/주요판결 **scourt.go.kr**
   - 학술논문 **KCI(kci.go.kr)**
   - 로펌·공익법단체 해설, 노동·법률 전문지, 신뢰할 언론
   - `WebSearch` 결과 요약 자체가 직접 `WebFetch`가 막혀도 사건번호·판시를 교차확인해 준다. **둘 이상 독립 출처**가 일치하면 확정으로 본다.
5. **제시**: 확인된 사건만 「대법원 0000. 0. 0. 선고 0000다0000 판결」 + 핵심 판시 + **출처/URL**로 인용하고, 질문 사안과의 **유사점·차이점**을 설명. 직접 원문을 못 본 경우 "원문 최종확인 권장"을 덧붙인다.
6. **최후에만 보류**: 여러 대체 출처로도 특정·일치가 안 될 때만 지어내지 말고 "확인 필요"로 표기하고 확인처를 안내.
